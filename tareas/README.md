En esta carpeta se deben  subir las soluciones de sus tareas mediante un **Pull Request**.

### Instrucciones:
1. Haga un *Fork* de este repositorio a su cuenta de GitHub.
2. Cree una rama específica para el taller (ej. `taller-01-pepitx-perez`).
3. Cree una subcarpeta dentro del taller correspondiente con su nombre: `Tareas/Taller_01/nombre_apellido/`.
4. Suba su notebook/script y envíen el *Pull Request* hacia la rama `main` del repo.
